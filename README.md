# Business Hotels — Générateur de signature e-mail

Page simple et responsive pour que chaque employé crée sa propre signature avec une identité visuelle commune.

## Publication sur GitHub Pages
1. Créez un dépôt GitHub nommé `business-hotels-signature`.
2. Téléversez `index.html` à la racine du dépôt.
3. Ouvrez **Settings → Pages**.
4. Choisissez **Deploy from a branch**, puis branche `main` et dossier `/ (root)`.
5. Enregistrez et partagez l'URL GitHub Pages générée.

Les champs sont traités localement dans le navigateur : aucune base de données n'est utilisée. Les employés n'ont pas besoin d'un accès en écriture au dépôt pour utiliser la page.

Remarque : GitHub Pages sert une page publique. Le code source HTML reste consultable par les visiteurs, même si seul le propriétaire peut modifier le dépôt.
